3) ROUTER CO GAYS 429 KHONG?
----------------------------
KHONG. Router chi chon tier:
- model co trong kilo_models -> chi goi Kilo; model khac (vd deepseek-v4.1-flash-free)
  -> chi goi tier 1 gateway :8000 (router.py KILO_UPSTREAMS logic).
- log VPS2 15:49:52Z: `upstream vps2-o2a -> 429, cooldown 30s` -> router nhan 429
  tu gateway, khong tao ra 429.
- log gateway cung thoi diem: key_id=CE0nZ, channel=key, legs CE0nZ:429 lap lai.
  => Quota do xay ra o BEN TRONG gateway VPS2, sau khi anonymous WARP het va
     gateway fallback sang Zen key duy nhat cua no (config zen_keys=1).
- VPS1 config zen_keys=0 -> khong co key fallback -> log la anon:429@direct.

4) VI SAO HAI MAY KHAC NHAU THAT
--------------------------------
| | VPS2 | VPS1 |
|---|---|---|
| Router :8090 | co | khong |
| OMP base URL | :8090 (router) | :8080 (gateway) |
| Zen key trong gateway | 1 (CE0nZ) | 0 |
| Duong khi anonymous het | fallback vao Zen key -> key 429 | fallback vao direct IP -> anon 429 |
| Kilo | qua router tier 2 | qua zen-gate :8787 rieng |

Router khong quyet dinh key hay direct; chinh gateway quyet dinh sau anonymous.
Tai lieu upstream (https://github.com/jasonxu114514/opencode2api) mo ta: free
model thu anonymous lane truoc, roi moi den authenticated tiers theo prefer order;
key la fallback, khong phai bat buoc.

5) CO NEN BO VONG KHONG?
------------------------
Khong nen chi de doi phu 429:
- tro OMP VPS2 thang :8000 van gap key tier CE0nZ vi gateway van co zen_keys=1;
  mat them Kilo tier 2 va catalog merge cua router.
- neu muon dong bo that su: deploy router len VPS1 va doi OMP provider VPS1 sang
  :8090, hoac nguoc lai bo router VPS2 va chuyen Kilo sang zen-gate :8787.
  Viec nay khong giam 429 - 429 nam o quota/key/direct, khong nam o so hop.
