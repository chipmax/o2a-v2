CACH DUNG VOI O2A (khong sua code)
----------------------------------
Chi can them vao mang `proxies` cua config.json (value that se duoc nguoi dung
dien, KHONG commit vao repo):

  "proxies": [
    "socks5h://<webshare-user>-rotate:<pass>@p.webshare.io:1080",
    "https://<axio-user>:<pass>@<host>:<port>",
    "socks5h://127.0.0.1:<sidecar-port>"
  ],
  "warp": { "enabled": true, "rotate_keys": true, ... }

Sidecar SurfShark/Lantern: sing-box SOCKS inbound + policy routing theo source
IP (ip rule from <tunnel-ip> table <n>), KHONG them route default vao main.
Kiem tra sau khi bat: `ip route show table main | head -2` phai giu nguyen.
